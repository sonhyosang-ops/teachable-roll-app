# 발모아구르기 동작 인식 웹앱

Teachable Machine Pose 모델을 사용해 발모아구르기 동작을 실시간으로 인식하는 정적 웹앱입니다.

## 기능

- 스마트기기 카메라 인식
- 화면 왼쪽 카메라, 오른쪽 결과 패널 배치
- 각 동작별 정확도 표시
- 정확도 60% 이상 `통과`, 60% 미만 `노력하세요` 표시

## 사용 모델

https://teachablemachine.withgoogle.com/models/LxVJHksKP/

## 동작 라벨

- 발모아구르기 준비
- 발모아구르기 연속동작 1
- 발모아구르기 연속동작 2
- 발모아구르기 연속동작 3
- 발모아구르기 종료
